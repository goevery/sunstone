# Google Cloud icons

These icons come from the official [Google Cloud icon library](https://cloud.google.com/icons). They are included locally so the architecture diagram renders without network access.

Current product icons are used for Compute Engine, Cloud SQL, and Cloud Storage. The remaining products use matching category icons from the same current library:

- Artifact Registry uses Developer Tools.
- Cloud Load Balancing uses Networking.
- Cloud Logging uses Observability.
- Memorystore uses Databases.
- Secret Manager uses Security & Identity.
